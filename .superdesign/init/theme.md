# Theme

Primary theme source: `styles.css`.

## CSS Approach

- Vanilla CSS.
- CSS custom properties in `:root`.
- No Tailwind, CSS modules, styled-components, or component library.

## Token Summary

- Background: `--bg: #e3e2de`
- Panel: `--panel: #ecebe6`
- Paper: `--paper: #f5f4f0`
- Dark panel: `--panel-dark: #5f666d`
- Ink: `--ink: #141414`
- Body text: `--text: #444343`
- Muted text: `--muted: #7a7a7a`
- Line: `--line: #c7c7c7`
- Accent: `--accent: #1351aa`
- Accent soft: `--accent-soft: #dbe6f6`
- Save: `--save: #0f4d2c`
- Radius: `--radius-lg: 26px`, `--radius-md: 18px`, `--radius-pill: 999px`
- Controls: `--control-height: 46px`, `--control-height-compact: 38px`, `--control-padding-x: 18px`

## Fonts

- Display/body: Helvetica Neue, Helvetica, Arial, sans-serif.
- Metadata: IBM Plex Mono.

## Full Theme Context

Use `styles.css` plus `.superdesign/design-system.md` as context for design work. `styles.css` is over 1000 lines, so pass line ranges relevant to the target page when using Superdesign draft commands.
