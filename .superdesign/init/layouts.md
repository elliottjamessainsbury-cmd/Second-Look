# Layouts

The app uses static HTML shells instead of layout components.

## Home Shell

- File: `index.html`
- Structure: `.page-shell` > `.app-topbar` > `.hero` > `.home-flow`
- Runtime rendering: `app.js`
- Styling: `styles.css`

## Saved Films Shell

- File: `saved.html`
- Structure: `.page-shell.saved-page-shell` > `.app-topbar` > `.saved-page-header` > `.saved-page-main`
- Runtime rendering: `app.js`
- Styling: `styles.css`

## Privacy Shell

- File: `privacy.html`
- Structure: `.page-shell.privacy-page-shell` > `.app-topbar` > `.privacy-card`
- Styling: `styles.css`
