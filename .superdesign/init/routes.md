# Routes

This is a static web app served from the project root.

## `/` and `/index.html`

- File: `index.html`
- Purpose: home, recommendation preview/input, account access, cinema showtimes.
- Runtime: `app.js`

## `/saved.html`

- File: `saved.html`
- Purpose: dedicated saved-films page.
- Runtime: `app.js`

## `/privacy.html`

- File: `privacy.html`
- Purpose: plain-language privacy note.
- Runtime: static only.
